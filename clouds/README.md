# Bulut katmanı dokuları

`clouds.webp` (tam çözünürlük) ve `clouds.lite.webp` (hızlı önizleme), Cosmos'un Dünya bulut katmanında kullanılır.

- Kaynak: [SatVisor](https://github.com/satvisorcom/satvisor) projesi, `public/textures/earth/`
- Lisans: AGPL-3.0 (bkz. `LICENSE`). Dosyalar değiştirilmeden, kaynağa atıfla yeniden dağıtılır.
- Amaç: sitenin üçüncü taraf bir depoya bağımlı olmaması.
